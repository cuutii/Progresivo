# 📖 Progresivo — Ejercicio de maqueta web en dos etapas

Proyecto de **aprendizaje**: una maqueta web construida en dos pasos para practicar cómo se pasa de HTML puro a HTML + CSS. La idea es comparar las dos versiones y entender qué aporta el CSS.

> ⚠️ Es material de estudio, no un producto terminado.

## Características

- **Pagina1.html** — primera etapa: maqueta básica usando **solo HTML**, con comentarios que explican cada etiqueta (`DOCTYPE`, `charset`, `viewport`, `title`...).
- **Pagina2.html** — segunda etapa: la misma maqueta evolucionada con **HTML semántico** (`header`, `nav`, `main`, `section`, `footer`) y un archivo de estilos externo.
- **estilos.css** — hoja de estilos compartida que vincula la Página 2.
- Código comentado, pensado para leer y estudiar.

## Cómo usarlo

Descargá el repositorio y abrí `Pagina1.html` y `Pagina2.html` en tu navegador (doble clic en cada uno). Comparalas para ver los cambios entre la primera y la segunda etapa.
